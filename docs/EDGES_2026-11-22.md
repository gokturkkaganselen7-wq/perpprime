# PerpPrime — Alternative Edge Tests

**Date:** 2026-11-22 · **Status:** paper only

> The trend rules lost money after the look-ahead fix. This report tests
> three structurally different hypotheses with the same honesty rules and
> the same cost model. **None of them passed the pre-registered bar in
> `docs/STRATEGY_CHARTER.md`.**

## 1. Method

| Rule | Implementation |
|---|---|
| Signal timing | Computed on a closed bar; filled at the **next bar open** |
| Ambiguous bar | Stop assumed first when stop and target share a candle |
| Gaps | A bar opening through the stop fills at the open (`stop_gap`) |
| Liquidation | Isolated-margin approximation, MMR 0.5%, 55 bps extra fee |
| Drawdown | Marked intrabar at the worst plausible price |
| Costs | 5.5 bps taker + 2 bps slippage per fill + real Bybit funding |
| Sizing | 0.5% equity risk, 3x leverage cap, 10,000 USDT per leg |
| Validation | 90d train / 30d test / 30d step, 9 windows per symbol |

## 2. Hypotheses and exact rules

### 2.1 Funding carry

**Economic rationale:** perpetual funding is a fee paid by the crowded
side to the other side. When 8h funding is rich, shorts are paid to hold
and the position is already crowded; the test asks whether that payment
survives directional risk and costs.

**Rules:** short when the last 8h funding is ≥ 1 bp (0.01%), long when it
is ≤ -1 bp. Stop 1.5 ATR, target 2R, time stop 24 bars, exit when funding
returns to zero. Funding is credited/charged every 8h stamp.

### 2.2 Opening-range breakout

**Economic rationale:** the first hours of the UTC day concentrate
overnight order flow; a close outside that range with above-average volume
can mark the direction of the session.

**Rules:** the first 4 hours of the UTC day define the range. A close
outside it on ≥ 1.2× the 20-bar average volume enters at the next open.
Stop 1.5 ATR, target 2R, the day end closes the trade.

### 2.3 Range mean reversion

**Economic rationale:** in a confirmed range, moves beyond 2 ATR from
EMA20 tend to be liquidity hunts rather than repricing; a reclaim candle
offers an entry back toward the mean.

**Rules:** only when the 4h regime is `range`. Long when price is ≥ 2 ATR
below EMA20 and the bar closes green; short on the mirror. Target EMA20,
stop 1.5 ATR, time stop 24 bars.

## 4. Cost sensitivity

The same 12-month window with **2× costs** (11 bps taker + 4 bps
slippage). A real edge should survive a doubling; a marginal one dies.

| Funding carry | -16.58% | -6.95% | -31.82% | -18.45% |
| Opening-range breakout | -47.69% | -42.57% | -31.77% | -40.68% |
| Range mean reversion | -12.20% | -5.79% | -5.05% | -7.68% |

## 5. Verdict against the charter

Criteria from `docs/STRATEGY_CHARTER.md` §5. A strategy passes only if
every row is a pass.

| Criterion | Funding carry | ORB | Range fade |
|---|---:|---:|---:|
| OOS mean > 0 | FAIL | FAIL | FAIL |
| OOS positive windows ≥ 6/9 | FAIL | FAIL | FAIL |
| OOS trades ≥ 30 per symbol | PASS | PASS | PASS |
| 12m PF ≥ 1.2 in ≥ 2/3 symbols | FAIL | FAIL | FAIL |
| 12m DD ≤ 10% | FAIL | FAIL | PASS |

**No strategy passed every criterion.** None is eligible for paper
forward testing as an edge candidate, let alone live capital.

## 6. What this does not test

| Gap | Why it matters |
|---|---|
| Delta-neutral carry | The spot leg is not in this repo; a single-leg carry short is directional |
| Liquidation cascades | No historical OI or liquidation prints |
| News and macro events | No event calendar in the historical data set |
| Grid execution | Multi-level fills need a different engine |
| Order-book slippage | Fixed 2 bps; size-dependent impact is not modelled |
| Altcoin universe | Only BTC/ETH/SOL were tested |

## 7. Reproduce

```bash
# 12 months
PYTHONPATH=src .venv/bin/python scripts/backtest_edges.py --strategy carry \
  --mode single --start 2025-11-14 --end 2026-11-14

# walk-forward
PYTHONPATH=src .venv/bin/python scripts/backtest_edges.py --strategy orb \
  --mode walkforward --start 2025-11-01 --end 2026-11-14

# cost stress
PYTHONPATH=src .venv/bin/python scripts/backtest_edges.py --strategy range \
  --mode single --start 2025-11-14 --end 2026-11-14 --fee-bps 11 --slip-bps 4
```
