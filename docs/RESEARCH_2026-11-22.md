# PerpPrime — Research Round 2

**Date:** 2026-11-22 · **Status:** paper only

> While re-running the walk-forward tests for this round, a **window-edge
> bug** was found in every engine: a position still open at the end of a
> test window was held until the last bar of the whole data file. That
> contaminated every previous walk-forward number. The engines are fixed
> (`end_i` is the last bar at or before `end_ms`) and every walk-forward
> below was re-run from scratch. The single-period tables were not
> affected because their window already ended at the data edge.

## 5. Funding dispersion (10 symbols, perp-perp)

The book shorts the highest-funding perps and longs the lowest, equal
notional, 3-day funding average, 7-day rebalance, 50% exposure per leg.

| Metric | 12 months |
|---|---:|
| Trades | 27 |
| PF | 1.29 |
| Max DD | 5.00% |
| Return | **+6.32%** |
| Funding P&L | -2.8 |

The funding P&L is **negative** in the 12-month window: the profit came
from the price legs, not from carry. The signal is a crowding rank, not
a funding harvest.

Walk-forward: 25 OOS trades, **+0.18%**/window,
positive 3/9, worst DD 11.08%.

Placebo (20 shuffled rankings): average 0.08%, best 2.58%. The real run (+6.32%) beats the placebo best, so the rank
carries information — but the start-date test is disqualifying: the same
default parameters return **+111%** from 2025-11-01 and **-0.9%** from
2025-11-14. A two-week shift in the start date must not flip the sign.

**Verdict: NO_EDGE.** Path-dependent, too few trades (25 OOS) and
fragile to the start date.

**No hypothesis clears Tier S.** The closest are:

- **Basis gross:** clear edge, but the retail fee bill is 8–21× the
  funding income. Only a VIP/maker tier can make it tradable.
- **Daily trend:** genuine net-positive premium, but its drawdown is
  25–55%, far outside the 8% cap. Volatility targeting could cut the
  drawdown, and the return with it; it would become a 10–15% annual
  strategy, not 40%.

## 8. The window-edge bug (audit note)

Every engine closed a window's open position at `rows[-1]` — the last
bar of the loaded file — instead of the last bar inside the window. For
full-period runs the two coincide, so the single-period tables stand.
For walk-forward tests the position leaked into later data, which could
flip a window's result. The fix is an `end_i` scan before the loop; a
regression test (`test_position_is_closed_at_the_window_edge_not_the_file_end`)
locks it down. All walk-forward tables in BACKTEST.md,
EDGES_2026-11-22.md and this report were regenerated after the fix.

## 9. Bottom line

Tier S was the right bar to set, and the honest answer is that nothing
reaches it with this data, this universe and retail costs. The brain
now encodes that: `cfos allocate` reads the measured registry and
returns **NO_TRADE** in every regime. That is not a failure of the
system; it is the system refusing to trade an edge it cannot prove.
